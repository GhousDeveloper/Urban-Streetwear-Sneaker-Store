## ⚡ Overview

**Street District** is a modern e-commerce storefront concept built around urban fashion, limited-edition sneakers, and contemporary streetwear culture.

The experience combines editorial campaign storytelling with product discovery and interactive shopping features. Visitors can explore collections, search the catalog, view product details, manage a wishlist, switch currencies, and interact with a shopping bag and checkout interface.

Designed with an obsidian-black foundation, district-orange highlights, bone-white sections, and acid-lime accents, Street District delivers a distinctive and responsive storefront experience.

## 🧰 Technology Stack

| Technology | Purpose |

## 🎨 Design System

The visual identity is built around four signature colors.

| Color | Hex | Application |
|---|---|---|
| Obsidian Black | `#080808` | Primary backgrounds |
| Bone Off-White | `#F0EFED` | Light sections |
| District Orange | `#F4511E` | CTAs and promotional highlights |
| Acid Lime | `#9EFF00` | Accent details and interactive highlights |

The result is a high-contrast aesthetic inspired by sneaker culture, underground fashion editorials, and contemporary streetwear brands.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the Repository

```bash
git clone https://github.com/GhousDeveloper/Urban-Streetwear-Sneaker-Store.git
```

### 2. Open the Project Directory

```bash
cd Urban-Streetwear-Sneaker-Store
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the storefront.

### Production Build

```bash
npm run build
npm run start
```

## 📱 Responsive Experience

Street District is designed to provide a consistent shopping interface across desktop, tablet, and mobile screen sizes.

The navigation, product discovery experience, shopping controls, and editorial sections are designed to adapt to different viewport sizes.
